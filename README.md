# 山西电力市场2026年10月价格预测与交易策略报告

基于2024年1月至2026年9月共994天、95,424条15分钟级历史数据的系统性分析。

## 内容

- 市场数据概览（价格走势、负荷、风光出力）
- 10月供需形势分析（动力煤价格、天气、风光预测、政策变化）
- 价格预测结果（分时段预测、三情景分析）
- 分主体交易策略（售电公司、火电厂、新能源场站、储能电站）
- 风险提示与应对建议

## 技术栈

- 纯 HTML + CSS（无构建步骤）
- ECharts 5（本地离线，无CDN依赖）
- 响应式布局，支持移动端
